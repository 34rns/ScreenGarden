# ScreenGarden 0.1.0

A free, offline garden for calmer screen habits. Android 8.0 (API 26) or later.

- Recoverable plants, explainable scores, focus timers and gentle rewards.
- Optional goals, reminders, quiet hours, compassion days and milestones.
- Local insights, weekly reflections and saved garden history.
- Light/dark/AMOLED, Spanish, plant packs, widgets, tile and live wallpaper.
- User-controlled PNG and validated JSON export/import. Optional app blocking stays off.

Download **ScreenGarden-v0.1.0.apk**. This is the optimized production build;
public screenshots use separate fake debug-only data. Allow installation from your
download app when Android asks. Usage access and notifications are optional.
Updates must use the same signing certificate; keep personal backups private.

The release workflow runs all four quality gates, production lint, offline/backup
manifest and immutable-schema checks, signature verification and alignment checks
before publication. SHA256SUMS.txt and signature.txt accompany the APK. Corresponding
source is available at this tag and through GitHub's source archives.

The quality pass verified 362 JVM tests and 20 Android 15 integration tests.
Screenshots/layout checks include themes, Spanish, RTL and larger text on several
emulator sizes. Physical-device/OEM reliability, actual reboot/process death,
complete API26 layouts, low-end performance, TalkBack listening and fluent Spanish
review remain unverified. Reminders/widgets are approximate; sleep can delay timers.
